# 🎮 Juego de la Memoria — TP Final

Trabajo práctico final de la materia **Introducción a la Programación**. Un juego de memoria por consola desarrollado en **PHP**, que permite simular partidas entre dos jugadores y consultar estadísticas de las partidas registradas.

![PHP](https://img.shields.io/badge/PHP-777BB4?style=flat&logo=php&logoColor=white)
![CLI](https://img.shields.io/badge/CLI-Terminal-4D4D4D?style=flat)

## 📌 ¿Qué hace?

El programa simula el clásico **Juego de la Memoria** en consola. Carga una colección de partidas ya jugadas y ofrece un menú interactivo:

1. **Jugar a Memoria** — iniciar una nueva partida entre dos jugadores.
2. **Mostrar un Juego** — ver el resultado de una partida específica.
3. **Mostrar el Primer Juego Ganador**.
4. **Mostrar Porcentaje de Juegos Ganados**.
5. **Mostrar Resumen de Jugador**.
6. **Mostrar Listado de Juegos Ordenado por Jugador 2**.
7. **Salir**.

## 🗂️ Estructura

| Archivo | Descripción |
|---------|-------------|
| `memoria.php` | Librería con las constantes y funciones del Juego de la Memoria (reutilizable). |
| `programaClaveriaVillagran.php` | Programa principal con el menú y la lógica de la aplicación. |

## ▶️ Cómo ejecutarlo

Requiere tener [PHP](https://www.php.net/) instalado.

```bash
php programaClaveriaVillagran.php
```
